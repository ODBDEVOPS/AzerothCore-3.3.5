## 📋 Instructions :
1. Cliquez sur "Add file" → "Upload files"
2. Glissez-déposez vos fichiers MPQ
3. Attendez la fin de l'upload
4. Le workflow d'extraction se lancera automatiquement

## ⚠️ Limites :
- Taille max : 100 Mo par fichier
- Extensions : .MPQ ou .mpq
